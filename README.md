# 🗡️ The Legend of Zelda: Ocarina of Time - Custom Native 3DS Build 🛡️

Este repositorio almacena una compilación empaquetada y lista para su instalación del port nativo de **The Legend of Zelda: Ocarina of Time (Nintendo 64)** para la familia de consolas Nintendo 3DS. 🎮

A diferencia de la emulación convencional, el código del juego se ejecuta de forma nativa en la CPU de la consola, permitiendo un rendimiento completo de **60 fps** en modelos *New 3DS* y **30 fps** en *Old 3DS*. ⚡

## 🛠️ Requisitos de Instalación en Hardware

Para jugar esta build de manera correcta en tu consola, asegúrate de cumplir con los siguientes archivos en tu tarjeta de memoria:

1. **📦 El Ejecutable (.cia):** Instala el archivo `oot.cia` disponible en la sección de **Releases** de este repositorio utilizando **FBI**.
   * 📱 **Código QR de Descarga Directa:**
   <p align="center">
      <img width="333" height="320" alt="image" src="https://github.com/user-attachments/assets/9e38ff79-2c6d-41f4-bdda-2322de4ecde6" />
    </p>

   
2. **💾 La ROM Descomprimida (Asset Pipeline):** ➡️ https://drive.google.com/drive/folders/1YZdwW6gOii35hnDgEc3wzJ9GuSNY8rjp?usp=drive_link
   * Copia el archivo de recursos generado `baserom-decompressed.z64` (obtenido legítimamente mediante la descompresión del cartucho original NTSC-U 1.0) en la siguiente ruta exacta de tu tarjeta SD:
     ```text
     sdmc:/3ds/oot/baserom-decompressed.z64
     ```
